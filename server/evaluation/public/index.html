What each score means
Overall field accuracy — higher is better
Correct field values ÷ scored field values. Unknown matches Unknown. A failed model request counts as incorrect for its eligible fields.
Complete-case accuracy — higher is better
Cases with all four fields correct ÷ fully scorable attempted cases. Cases with disputed fields are outside this metric.
Invented-value rate — lower is better
Non-empty model values where the reference is Unknown ÷ Unknown reference slots with valid predictions. Includes fee, date and exact time. Model errors are reported separately.
Enough-info accuracy — higher is better
Correct Yes/No decisions ÷ scored decisions.
False Yes rate — lower is better
Predicted Yes when the reference is No ÷ reference-No cases with valid model decisions. This is not booking confirmation.
